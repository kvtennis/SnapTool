# SnapTool · Mac 截图小工具

原生 Swift（AppKit）编写的菜单栏截图工具，无依赖、无 Electron、安装包仅约 300KB。

## 位置

- 应用：`/Users/fengyu/Applications/SnapTool.app`（已安装并运行，菜单栏相机图标）
- 源码：`/Users/fengyu/WorkBuddy/2026-09-24-14-59-43/SnapTool/`
- 重新构建：`cd SnapTool && ./build.sh`，产物在 `dist/SnapTool.app`

## 快捷键

| 快捷键 | 功能 |
|---|---|
| ⌃⌥A | 区域截图 → 打开标注编辑器 |
| ⌃⌥C | 区域截图 → 直接复制到剪贴板 |
| ⌃⌥F | 全屏截图 |
| ⌃⌥W | 窗口截图（可切阴影） |
| ⌃⌥D | 延时区域截图（3/5/10 秒可设置） |
| ⌃⌥Z | 重复上一次截图模式 |

## 编辑器（截图后自动弹出）

- **标注工具**：矩形、椭圆、箭头、直线、画笔、文字、序号、马赛克
- **快捷键**：`V 移动 / R 矩形 / E 椭圆 / A 箭头 / L 直线 / P 画笔 / T 文字 / M 马赛克 / N 序号`
- 8 色调色板 + 4 档线宽；⌘Z 撤销、⇧⌘Z 重做
- **⌘C 复制**、**⌘S 保存**、**⌘E 复制并关闭**、Esc 关闭
- **直接拖动图片**即可拖进微信 / QQ / 浏览器等任意应用
- ⌘+滚轮 / 触控板捏合缩放，⌘0 适应窗口

## 设置（菜单栏图标 → 设置…）

- 保存位置（默认 `~/Pictures/SnapTool`，文件名 `SnapTool_日期_时间.png`）
- 自动复制到剪贴板 / 是否打开编辑器 / 提示音 / 捕获鼠标指针 / 窗口阴影 / 延时时长
- 最近 10 张截图快速打开

## 首次使用（重要）

第一次截图时 macOS 会要求**「屏幕录制」权限**——**不授权截到的就是空白/透明图**。

1. 点菜单栏相机图标 → 顶部会显示当前权限状态（✅ 已授权 / ⚠️ 未授权）
2. 未授权时点「检查 / 修复屏幕录制授权」→「打开系统设置」
3. 在「隐私与安全性 → 屏幕录制」中打开 **SnapTool** 开关
   （列表里没有的话，点 + 添加 `/Users/fengyu/Applications/SnapTool.app`）
4. 若勾选后仍空白：菜单栏 → 退出 SnapTool → 重新打开

**App 内置了防护**：未授权时按快捷键会直接弹窗引导，不会再产出空白图；即使漏网，截图后会自动检测全透明/纯色图并提示。

> 注意：重新编译（./build.sh）会改变应用签名，可能需要到系统设置里重新勾选一次屏幕录制权限。
